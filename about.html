About Numtax

A project for exploring integers, discovering their properties, and connecting computation with mathematics.

An independent project in development

What is Numtax?

Numtax is a web-based project for classifying and investigating integers. It brings together number properties, mathematical relationships, visual explorations, and explanations of the methods used to obtain results.

The aim is not just to return a label for a number, but to make it easier to explore why a number has a particular property and how that property relates to other ideas in mathematics.

Project principles

Mathematical clarity

Definitions should be explicit, terminology should be consistent, and mathematical claims should be supported by reasoning or suitable references.

Transparent computation

The project aims to explain which methods are used, what assumptions they make, and where their limitations lie.

Useful visual exploration

Visualizations should help users investigate mathematical structures rather than serve as decoration alone.

Accessible by design

Numtax is designed as a web experience that can be explored through a browser without requiring a local mathematics software installation.

How results are documented

Computational output and mathematical proof are not the same thing. A program can provide evidence, examples, or a useful way to explore a conjecture, but those results do not by themselves establish a general mathematical theorem.

As the project develops, its documentation will distinguish between definitions, computed results, implementation details, and formal mathematical arguments.

Current status

Numtax is a work in progress. Features, explanations, tests, and documentation will evolve as the implementations are reviewed and expanded.

This page will be updated with more information about the project's development, its maintainers, and ways to contribute as those details are established.
